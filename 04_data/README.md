# Data

`raw/` contains the immutable inputs to the packaged analysis:

- `raw/safetypool/`: 23 SafetyPool seed directories;
- `raw/baselines/`: 23 seed directories, each with Epsilon-Greedy, NoisyNet,
  and RND results.

Every seed–method `all_episode_results.csv` contains 500 training and 300 test
records. Only the test records are used for the paper comparisons.

`processed/` is regenerated by
`02_source_code/analysis/generate_ieee_results.py`. It contains seed-level
metrics, aggregate IQMs and confidence intervals, paired statistical tests,
and the completeness audit.

Neural-network weights and SafetyPool training-memory snapshots are not
included because the figures and statistics depend only on the result records.
